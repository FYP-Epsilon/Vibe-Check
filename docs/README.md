# VibeCheck Internal Documentation & Wiki

Welcome to the VibeCheck knowledge base. This directory contains all the contextual information required to understand, develop, and extend the framework.

## Directory Structure
* **/architecture**: System design, interim reports, and data flow diagrams.
* **/research**: Reference materials, formal methods literature, and library documentation (e.g., SPOT, Z3).
* **/api_and_schemas**: Data contracts, specifically the WIR JSON schema format.

**Note for AI Agents:** When implementing new features, please refer to the documents in this directory to ensure your code aligns with the formal verification parameters defined in our research.
