## 1. Introduction

Module 02 requires a systematic, repeatable evaluation dataset to validate its correctness claims. Rather than relying solely on the IBM Flow-Bench dataset (which contains 101 test cases with proprietary API call patterns), we generate a **4-layer evaluation dataset** that provides:

1. **Fresh workflows** not seen during development (prevents overfitting)
2. **Known structural properties** (ground truth for V3 metrics)
3. **Known semantic mutations** (ground truth for V1/V2 detection rates)
4. **Stress-test edge cases** (boundary conditions for all components)

This document describes the complete methodology, implementation, and expected outputs.

## 2. Flow-Bench Methodology Analysis

### 2.1 Dataset Structure

The IBM Flow-Bench dataset [^19^] consists of 101 incremental test cases stored in `conditional_ootb.yaml`:

```yaml
tests:
  - _metadata:
      tags: ["1", "linear"]
      uid: 1
    input:
      utterance: "Create a new Jira issue and then create a github repository."
      prior_sequence: ""
      prior_context: []
    expected_output:
      sequence:
        - "issue = Jira_Issue__2_0_0__create_Issue()\nrepository = GitHub_Repository__3_0_0__create_Repository()"
      bpmn:
        - $ref: "output/uid_1_output.bpmn"
```

### 2.2 Taxonomy of Test Cases

From our analysis of the `tags` field across all 101 test cases:

| Tag Category | Count | Description | Example |
|-------------|-------|-------------|---------|
| `linear` | 34 | Sequential API calls | Create issue, then create repository |
| `conditional` | 19 | If/else on object properties | If priority=high, do X, else do Y |
| `conditional_update_replace` | 26 | Replace action in existing workflow | "Send email *instead of* slack" |
| `conditional_update_add` | 21 | Add branch to existing workflow | "Also add else clause" |
| `conditional_update_delete` | 14 | Remove action from workflow | "Remove the notification step" |
| `linear_update_add` | 11 | Add step to linear sequence | Append action |
| `linear_update_replace` | 6 | Replace step in linear sequence | Swap action |
| `linear_update_delete` | 5 | Remove step from linear sequence | Delete action |
| `user_task` | 16 | Include human approval step | `user_task("validate")` |

### 2.3 Key Insight: Incremental Build Pattern

Flow-Bench uses an **incremental build pattern** — complex test cases are generated by applying systematic transformations to simpler base workflows. This is the methodology we replicate.

```
Base:        "Create Jira issue, then create GitHub repository" (uid 1, linear)
                ↓ conditional_update_replace
Variant:     "Send email *instead of* creating repository" (uid 11)
                ↓ conditional_update_add
Variant:     "If urgent, send email *else* create repo" (uid 12)
                ↓ conditional_update_delete
Variant:     "Remove the email step" (uid 13)
```

### 4.4 Implementation

```python
# eval_data/generate_golden.py
import asyncio
import json
import os
from dataclasses import asdict
from typing import List
from openai import AsyncOpenAI

# Import API vocabulary
from .api_vocab import API_VOCABULARY

COMPLEXITY_LEVELS = [
    "linear",
    "conditional", 
    "loop",
    "conditional_loop",
    "nested_loop",
    "deep_conditional"
]


class GoldenWorkflowGenerator:
    """
    Generates fresh golden workflows using GPT-4o-mini.
    
    Produces workflows NOT in Flow-BENCH with known ground-truth properties.
    Each workflow includes the Python IR + expected structural metrics.
    
    Cost: ~50 workflows × ~1.5K tokens = ~$0.40 total
    """

    def __init__(self, api_key: str = None):
        self.client = AsyncOpenAI(
            api_key=api_key or os.environ["OPENAI_API_KEY"]
        )
        self.model = "gpt-4o-mini-2024-07-18"

    async def generate_batch(
        self,
        count: int = 50,
        output_file: str = "eval_data/datasets/layer1_golden.json"
    ) -> List[dict]:
        """Generate N golden workflows distributed across complexity levels."""
        
        tasks = []
        for i in range(count):
            complexity = COMPLEXITY_LEVELS[i % len(COMPLEXITY_LEVELS)]
            tasks.append(self._generate_one(i, complexity))
        
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        # Filter valid results
        workflows = []
        for r in results:
            if isinstance(r, dict) and "python_ir" in r:
                r["source"] = "synthetic_gpt4o_mini"
                r["layer"] = 1
                r["validated"] = False  # Set True after manual review
                workflows.append(r)
        
        # Save
        os.makedirs(os.path.dirname(output_file), exist_ok=True)
        with open(output_file, 'w') as f:
            json.dump(workflows, f, indent=2)
        
        print(f"[GoldenGenerator] Generated {len(workflows)}/{count} valid workflows")
        print(f"[GoldenGenerator] Saved to {output_file}")
        
        return workflows

    async def _generate_one(self, idx: int, complexity: str) -> dict:
        """Generate a single golden workflow."""
        
        # Select random API categories for variety
        import random
        categories = random.sample(list(API_VOCABULARY.keys()), 
                                   k=min(2, len(API_VOCABULARY)))
        api_text = "\n".join(
            f"{cat}: {', '.join(API_VOCABULARY[cat]['ops'])}"
            for cat in categories
        )
        
        prompt = GOLDEN_GENERATION_PROMPT.format(
            idx=idx,
            complexity=complexity,
            api_vocab=api_text
        )
        
        response = await self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0.7,
            response_format={"type": "json_object"},
            max_tokens=2000,
            seed=idx  # Reproducible
        )
        
        return json.loads(response.choices[0].message.content)

    def validate_workflow(self, workflow: dict) -> bool:
        """
        Basic validation of generated workflow:
        1. Python IR is syntactically valid
        2. Contains a function definition
        3. Returns a string
        4. Has at least one API call
        """
        try:
            import ast
            tree = ast.parse(workflow["python_ir"])
            
            # Check for function definition
            funcs = [n for n in ast.walk(tree) if isinstance(n, ast.FunctionDef)]
            if not funcs:
                return False
            
            # Check for return statement
            returns = [n for n in ast.walk(tree) if isinstance(n, ast.Return)]
            if not returns:
                return False
            
            return True
        except (SyntaxError, KeyError):
            return False


if __name__ == "__main__":
    gen = GoldenWorkflowGenerator()
    workflows = asyncio.run(gen.generate_batch(count=50))
```

## 5. Layer 2: FLOW-BENCH Derivatives (Augmented Variants)

### 5.1 Purpose

Take existing base workflows and apply **systematic transformations** to create variants with known structural properties. This tests whether Module 02's V3 extractor correctly handles:
- New guard conditions
- Added loop structures
- Fused sequential workflows

### 5.3 Implementation

```python
class FlowBenchAugmenter:
    """
    Generates augmented variants of existing workflows.
    
    Uses GPT-4o-mini for structural transformations. Each transformation
    is applied to a base workflow to produce a variant with known properties.
    """

    def __init__(self):
        from openai import AsyncOpenAI
        import os
        self.client = AsyncOpenAI(api_key=os.environ["OPENAI_API_KEY"])
        self.model = "gpt-4o-mini-2024-07-18"

    async def augment_workflow(
        self,
        base_workflow: dict,
        operator: str,
        second_workflow: dict = None
    ) -> dict:
        """
        Apply an augmentation operator to a base workflow.
        
        Args:
            base_workflow: The original workflow dict with 'python_ir' field
            operator: One of AUGMENTATION_REGISTRY keys
            second_workflow: Required only for 'fuse_sequential' operator
            
        Returns:
            Augmented workflow with metadata about the transformation
        """
        config = AUGMENTATION_REGISTRY[operator]
        
        # Build prompt
        if operator == "fuse_sequential":
            prompt = config["prompt_template"].format(
                code1=base_workflow["python_ir"],
                code2=second_workflow["python_ir"]
            )
        else:
            prompt = config["prompt_template"].format(
                code=base_workflow["python_ir"]
            )
        
        # Call LLM for transformation
        response = await self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0.2,  # Low — structural transforms need precision
            max_tokens=1500
        )
        
        new_code = response.choices[0].message.content.strip()
        new_code = self._strip_markdown(new_code)
        
        return {
            "uid": f"{base_workflow['uid']}_{operator}",
            "base_uid": base_workflow["uid"],
            "augmentation_type": operator,
            "preserves_semantics": config["preserves_semantics"],
            "original_code": base_workflow["python_ir"],
            "augmented_code": new_code,
            "layer": 2
        }

    async def generate_all_augmentations(
        self,
        base_workflows: List[dict],
        output_file: str = "eval_data/datasets/layer2_augmented.json"
    ) -> List[dict]:
        """Generate all augmentation variants for a set of base workflows."""
        all_variants = []
        
        for base in base_workflows:
            for operator in AUGMENTATION_REGISTRY:
                if operator == "fuse_sequential":
                    # Pair with a random other workflow
                    import random
                    other = random.choice([w for w in base_workflows 
                                          if w["uid"] != base["uid"]])
                    variant = await self.augment_workflow(base, operator, other)
                else:
                    variant = await self.augment_workflow(base, operator)
                all_variants.append(variant)
        
        # Save
        os.makedirs(os.path.dirname(output_file), exist_ok=True)
        with open(output_file, 'w') as f:
            json.dump(all_variants, f, indent=2)
        
        return all_variants

    @staticmethod
    def _strip_markdown(code: str) -> str:
        if code.startswith("```python"):
            code = code[9:]
        elif code.startswith("```"):
            code = code[3:]
        if code.endswith("```"):
            code = code[:-3]
        return code.strip()
```

## 6. Layer 3: Seeded Bug Mutants (Mutation Testing)

### 6.1 Purpose

Generate **syntactic mutations** of correct workflow code to validate that Module 02's V1/V2/V3 detects semantic alterations. This is the gold standard for evaluating verification effectiveness [^41^][^44^].

### 6.2 Mutation Operators

Based on standard mutation testing literature [^37^][^43^] adapted for Python workflow code:

| Operator | Code | Description | Semantic Effect | Detection Target |
|----------|------|-------------|----------------|------------------|
| **ROR** | `==` → `!=` | Relational Operator Replacement | Alters branch condition | V1 (trace divergence), V2 (guard CNF) |
| **AOR** | `+` → `-` | Arithmetic Operator Replacement | Alters computed values | V1 (state comparison) |
| **COR** | `and` → `or` | Conditional Operator Replacement | Alters compound guard | V2 (guard CNF change) |
| **COD** | `not x` → `x` | Conditional Operator Deletion | Inverts guard sense | V1, V2 |
| **BOR** | Swap if/else | Branch body swap | Preserves semantics | Should NOT be detected (equivalent) |
| **SVR** | `x.prop` → `y.prop` | Scalar Variable Replacement | Wrong variable in guard | V1 (wrong state), V2 (type error) |
| **STR** | Delete statement | Statement Removal | Missing API call | V1 (trace length), V3 (node count) |
| **SDI** | Duplicate statement | Statement Duplication | Extra API call | V1 (trace length), V3 (node count) |
| **RER** | Return value change | Return Expression Replacement | Wrong output | V1 (return value diff) |
| **JTD** | `break` → `continue` | Jump Target Destruction | Wrong loop exit | V1 (trace path), V3 (CFG edge) |

### 6.3 Implementation

```python
# eval_data/mutation_engine.py
import ast
import copy
import random
from typing import List, Dict, Optional, Tuple
from dataclasses import dataclass


@dataclass
class Mutant:
    """A single mutant with full metadata."""
    mutant_id: str
    operator: str
    original_code: str
    mutated_code: str
    is_semantic_altering: bool
    mutation_point: str  # Description of where mutation was applied
    
    # Ground truth for evaluation
    expected_detection: str  # "v1", "v2", "v3", "combined", or "none" (for equivalent)


class WorkflowMutator(ast.NodeTransformer):
    """
    AST-based mutation engine for Python workflow code.
    
    Applies one mutation per invocation. Multiple mutations to the same
    source require multiple mutator instances.
    
    Based on standard mutation testing operators from Ammann & Offutt (2008)
    and PITest implementation patterns.
    """

    def __init__(self, mutation_type: str, mutation_index: int = 0):
        self.mutation_type = mutation_type
        self.mutation_index = mutation_index
        self.applied_count = 0
        self.target_index = mutation_index  # Which occurrence to mutate

    # ─── ROR: Relational Operator Replacement ──────────────────────────
    
    def visit_Compare(self, node: ast.Compare) -> ast.AST:
        self.generic_visit(node)
        
        if self.mutation_type != "ROR":
            return node
        if not node.ops:
            return node
            
        # Map each operator to its replacements
        ROR_MAP = {
            ast.Eq: [ast.NotEq, ast.Lt, ast.Gt],
            ast.NotEq: [ast.Eq, ast.LtE, ast.GtE],
            ast.Lt: [ast.Gt, ast.LtE, ast.Eq],
            ast.LtE: [ast.Lt, ast.Eq, ast.GtE],
            ast.Gt: [ast.Lt, ast.GtE, ast.Eq],
            ast.GtE: [ast.Gt, ast.LtE, ast.Eq],
        }
        
        op_type = type(node.ops[0])
        if op_type not in ROR_MAP:
            return node
            
        if self.applied_count == self.target_index:
            # Apply mutation: replace with random alternative
            new_op_cls = random.choice(ROR_MAP[op_type])
            node.ops = [new_op_cls()]
            self.applied_count += 1
            return node
        else:
            self.applied_count += 1
            return node

    # ─── COR: Conditional Operator Replacement ─────────────────────────
    
    def visit_BoolOp(self, node: ast.BoolOp) -> ast.AST:
        self.generic_visit(node)
        
        if self.mutation_type != "COR":
            return node
            
        op_type = type(node.op)
        if op_type == ast.And:
            if self.applied_count == self.target_index:
                node.op = ast.Or()
                self.applied_count += 1
            else:
                self.applied_count += 1
        elif op_type == ast.Or:
            if self.applied_count == self.target_index:
                node.op = ast.And()
                self.applied_count += 1
            else:
                self.applied_count += 1
                
        return node

    # ─── BOR: Branch body swap ────────────────────────────────────────
    
    def visit_If(self, node: ast.If) -> ast.AST:
        self.generic_visit(node)
        
        if self.mutation_type != "BOR":
            return node
            
        if not node.orelse:
            return node  # No else to swap
            
        if self.applied_count == self.target_index:
            node.body, node.orelse = node.orelse, node.body
            self.applied_count += 1
        else:
            self.applied_count += 1
            
        return node

    # ─── STR: Statement Removal ───────────────────────────────────────
    
    def visit_Assign(self, node: ast.Assign) -> ast.AST:
        self.generic_visit(node)
        
        if self.mutation_type != "STR":
            return node
            
        if self.applied_count == self.target_index:
            # Return a Pass node (no-op) instead of the assignment
            self.applied_count += 1
            return ast.Pass()
        else:
            self.applied_count += 1
            return node

    # ─── SDI: Statement Duplication ───────────────────────────────────
    
    # Handled at the statement-list level in visit_FunctionDef
    
    # ─── JTD: Jump Target Destruction ─────────────────────────────────
    
    def visit_Break(self, node: ast.Break) -> ast.AST:
        if self.mutation_type == "JTD":
            if self.applied_count == self.target_index:
                self.applied_count += 1
                return ast.Continue()
            self.applied_count += 1
        return node
    
    def visit_Continue(self, node: ast.Continue) -> ast.AST:
        if self.mutation_type == "JTD":
            if self.applied_count == self.target_index:
                self.applied_count += 1
                return ast.Break()
            self.applied_count += 1
        return node

    # ─── RER: Return Expression Replacement ───────────────────────────
    
    def visit_Return(self, node: ast.Return) -> ast.AST:
        self.generic_visit(node)
        
        if self.mutation_type != "RER":
            return node
            
        if node.value and isinstance(node.value, ast.Constant):
            if self.applied_count == self.target_index:
                # Mutate string return value
                if isinstance(node.value.value, str):
                    node.value.value = f"mutated_{node.value.value}"
                    self.applied_count += 1
            else:
                self.applied_count += 1
                
        return node


def apply_mutation(source_code: str, mutation_type: str, index: int = 0) -> Tuple[str, bool]:
    """
    Apply a single mutation to workflow code.
    
    Returns:
        (mutated_code, was_applied): The mutated code and whether the mutation
        was actually applied (some operators may not be applicable to all code)
    """
    tree = ast.parse(source_code)
    mutator = WorkflowMutator(mutation_type, index)
    mutated_tree = mutator.visit(tree)
    ast.fix_missing_locations(mutated_tree)
    
    was_applied = mutator.applied_count > 0
    
    try:
        mutated_code = ast.unparse(mutated_tree)
    except Exception:
        return source_code, False
    
    return mutated_code, was_applied


def generate_mutants(
    source_code: str,
    n_per_type: int = 20,
    base_uid: str = "unknown"
) -> List[Mutant]:
    """
    Generate all mutants for a given workflow.
    
    Produces up to n_per_type × 8 operator types = ~160 mutants.
    Filters out mutations that couldn't be applied.
    
    Args:
        source_code: The original (correct) Python workflow code
        n_per_type: How many mutations of each type to attempt
        base_uid: Identifier for the base workflow
        
    Returns:
        List of successfully applied Mutant objects
    """
    operators = {
        "ROR": {"semantic": True, "detect_by": "combined"},
        "COR": {"semantic": True, "detect_by": "v2"},
        "BOR": {"semantic": False, "detect_by": "none"},  # Equivalent!
        "STR": {"semantic": True, "detect_by": "v1"},
        "JTD": {"semantic": True, "detect_by": "v1"},
        "RER": {"semantic": True, "detect_by": "v1"},
    }
    
    all_mutants = []
    
    for op_type, config in operators.items():
        for i in range(n_per_type):
            mutated, applied = apply_mutation(source_code, op_type, i)
            
            if applied and mutated != source_code:
                all_mutants.append(Mutant(
                    mutant_id=f"{base_uid}_{op_type}_{i}",
                    operator=op_type,
                    original_code=source_code,
                    mutated_code=mutated,
                    is_semantic_altering=config["semantic"],
                    mutation_point=f"{op_type} at occurrence {i}",
                    expected_detection=config["detect_by"]
                ))
    
    return all_mutants
```

### 6.4 Mutation Score Calculation

```python
def calculate_mutation_score(mutants: List[Mutant], results: Dict[str, dict]) -> dict:
    """
    Calculate mutation testing metrics from verification results.
    
    Args:
        mutants: List of all generated mutants
        results: Dict mapping mutant_id → certificate from Module 02
        
    Returns:
        Metrics dict with detection rates
    """
    semantic_mutants = [m for m in mutants if m.is_semantic_altering]
    equivalent_mutants = [m for m in mutants if not m.is_semantic_altering]
    
    # Detection: combined < 0.95 means "caught"
    semantic_detected = sum(
        1 for m in semantic_mutants 
        if results.get(m.mutant_id, {}).get("combined", 1.0) < 0.95
    )
    
    # False positives: equivalent mutants wrongly rejected
    equivalent_rejected = sum(
        1 for m in equivalent_mutants
        if results.get(m.mutant_id, {}).get("combined", 1.0) < 0.95
    )
    
    return {
        "total_mutants": len(mutants),
        "semantic_mutants": len(semantic_mutants),
        "equivalent_mutants": len(equivalent_mutants),
        "semantic_detected": semantic_detected,
        "equivalent_rejected": equivalent_rejected,
        "detection_rate": semantic_detected / len(semantic_mutants) if semantic_mutants else 0,
        "false_positive_rate": equivalent_rejected / len(equivalent_mutants) if equivalent_mutants else 0,
        "target_detection": 0.95,  # 95% target
        "target_false_positive": 0.05  # 5% target
    }
```
