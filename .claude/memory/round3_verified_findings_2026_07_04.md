**Key design insight for the fix session**: giving the interpreter an exec env is necessary but NOT sufficient. Stub-call assignments are WIR *block* nodes — neither side emits task events for them (`task_patterns=[function_name]` only), so leaf drop-step mutants stay invisible even with working state. The full fix is task-observability alignment: pass stub names as `task_patterns` to the collector AND make the reference interpreter emit task events when a statement calls a known task pattern. Then drop/reorder/early-return become native LCS divergences and negate-guard is caught via which stubs execute per branch. Collector's existing `observables` snapshots are a future hook for value-level comparison if needed.
